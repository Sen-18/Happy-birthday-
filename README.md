# 🎂 Happy Birthday Adah!

A mobile-friendly, funny + lovely interactive birthday card made with plain HTML, CSS and JavaScript.

## Files

- `index.html` — the card content
- `style.css` — mobile-first design
- `script.js` — screen transitions + confetti
- `assets/` — Adah's photos

## GitHub Pages

1. Upload everything in this folder to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and **/(root)**.
5. Save.
6. Open the Pages URL GitHub gives you.

The site is designed to work especially well on phones.
