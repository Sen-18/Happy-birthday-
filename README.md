# Birthday Card 🎂

A lightweight interactive birthday card made with plain HTML, CSS and JavaScript.

## Customize

Open `index.html` and replace every `[NAME]` with the birthday person's name.
You can also edit the message and signature directly in the HTML.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

After GitHub finishes publishing, your shareable site will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
